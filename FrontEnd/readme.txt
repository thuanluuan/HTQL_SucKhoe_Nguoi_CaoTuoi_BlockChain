# FrontEnd - Hệ Thống Quản Lý Sức Khỏe Người Cao Tuổi (Blockchain)

Đây là thư mục FrontEnd của dự án Hệ thống quản lý sức khỏe người cao tuổi sử dụng công nghệ Blockchain.

## Yêu cầu cài đặt

Đảm bảo bạn đã cài đặt các công cụ sau:
- [Node.js](https://nodejs.org/) (Phiên bản LTS khuyến nghị)
- [npm](https://www.npmjs.com/) hoặc [Yarn](https://yarnpkg.com/)

## Hướng dẫn sử dụng

### 1. Cài đặt dependencies

Di chuyển vào thư mục FrontEnd và chạy lệnh để tải các gói thư viện cần thiết:

```bash
npm install
# hoặc
yarn install
```

### 2. Chạy môi trường Development

Để khởi chạy ứng dụng ở chế độ phát triển (thường là localhost:3000):

```bash
npm start
# hoặc
yarn start
```

### 3. Build cho Production

```bash
npm run build
```
